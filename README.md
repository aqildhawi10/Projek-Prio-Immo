**SMART-Grad (Sistem Manajemen & Akurasi Rekap Total Kelulusan)**

**Deskripsi Singkat**
SMART-Grad (Sistem Manajemen & Akurasi Rekap Total Kelulusan) adalah program berbasis
teks buatan Pascal untuk mengelola nilai mahasiswa. Programnya memakai menu interaktif
yang terus tampil sampai pengguna memilih keluar.
Untuk setiap mahasiswa, pengguna mengisi NIM, nama, nilai tugas, nilai UTS, dan nilai UAS.
Nilai akhir dihitung dari tugas 20%, UTS 30%, dan UAS 50%, lalu diubah menjadi huruf mutu
A sampai E. Mahasiswa dengan nilai A, B, atau C berstatus LULUS, sedangkan yang mendapat
D atau E berstatus TIDAK LULUS. Kalau ada nilai di luar rentang 0 sampai 100, data mahasiswa
itu dianggap tidak valid dan dilewati.

**Fitur-Fitur Utama**
1. Input Nilai Mahasiswa: memasukkan data beberapa mahasiswa sekaligus, lengkap dengan validasi nilai.
2. Tampilkan Rekap Nilai: menampilkan tabel berisi NIM, nama, nilai akhir, huruf mutu, dan status kelulusan seluruh mahasiswa.
3. Statistik Nilai: menampilkan nilai tertinggi dan terendah beserta nama mahasiswanya.
4. Cari Data Mahasiswa: mencari data mahasiswa berdasarkan NIM.
5. Keluar: mengakhiri program.
